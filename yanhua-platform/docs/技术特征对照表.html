〇、阅读方法

  1. 本表把方案拆成 7 组技术特征（S0~S6，共 27 项）。每项特征给出：技术内容 → 实现文件与行号 → 关键函数 → 关键参数 → 技术效果。
  2. 行号格式为 文件路径:行号，相对 patent-src/ 目录。
  3. 特征编号 S1~S5 与页面编号、功能阶段编号一致，可直接对应到 pages/s1.html~pages/s5.html 五个功能页。
  4. 全部阈值参数集中在 js/core/01-params.js，是该方案唯一的数值边界来源，方便审查与调整。
