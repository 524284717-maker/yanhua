# 江西省烟花爆竹产业全链条监管服务平台 · 系统说明

> 对应工程目录：`platform/`（11 个页面）
> 共享资源：`shared/geo-data.js`（省市县真实边界 GeoJSON）、`assets/`（品牌图标、监控抓拍图）

---

## 一、系统定位

面向省级烟花爆竹产业的全链条数字化监管，以**大屏态势感知**为主要呈现形态，
把分散在采购、生产、仓储、运输、出口、经营、燃放、执法等环节的数据汇聚到统一界面上，
并支持从省级逐级下钻到具体企业与点位。

页面均为**离线单文件 HTML**，内联样式与脚本，仅外部依赖 ECharts 5.4.3（CDN）与 `shared/geo-data.js`。

## 三、导航结构

11 个页面共用同一套顶部导航，顺序为：

```
态势总览 · 采购态势 · 生产态势 · 仓储态势 · 运输态势 · 出口态势
· 经营态势 · 燃放态势 · 打非治违 · 智能监控中心 · 业务管理
```

页面之间以**裸文件名互链**（如 `href="warehouse.html"`），因此在同一目录内整体搬迁时链接自动保持有效 ——
这也是工程把这 11 个页面放在同一个 `platform/` 目录下的原因。

页头**不含时间与天气**，导航项居中；系统名称统一为「江西省烟花爆竹产业全链条监管服务平台」。

## 四、下钻引擎

六个环节页共用同一套下钻实现，核心约定如下。

### 4.1 数据模型：父级总量逐级拆分，保证上下级自洽

```js
const ROOT = { name: '江西省', level: 0, prod: 860, stop: 92, workers: 48200, ... };
const METRICS = [
  { key: 'prod', label: '在产企业', unit: '家', dec: 0, tbl: true },
  ...
];
const MAIN_KEY = 'prod', MAIN_LABEL = '在产', MAIN_UNIT = '家';
```

不写死任何一级的具体数值，而是由 `childNodes(parent)` 调用 `splitTo()` 把父级总量按稳定哈希权重
拆给子节点，末位用**差额补齐**，因此各级求和恒等于上级总量。

### 4.2 子树生成

```js
function childNamesOf(node) {
  if (node.level === 0) return CITY_NAMES.slice();                  // 省 → 11 个设区市
  if (node.level === 1) return (CITY_COUNTIES[node.name] || []);    // 市 → 真实县区
  if (node.level === 2) { /* 稳定哈希从乡镇池取 3 个 */ }
  if (node.level === 3) { /* 由乡镇名 + 企业前缀生成 3 家企业 */ }
  return [];
}
```

省、市两级使用**真实行政区划名称**；乡镇与企业为**确定性生成**（同名同结果），保证同一节点每次进入内容一致。

### 4.3 地图与点位

- `shared/geo-data.js` 提供 `GEO_DATA`（键为 adcode），并注册
  `ensureProvinceMap` / `ensureCityMap` / `ensureCountyMap` 三个地图注册函数。
- 县级以下（乡镇、企业）没有真实边界数据，改用**面内散点**表示：
  `featPoints()` 在 bbox 上网格采样 + 射线法过滤 + 最远点采样，得到面内均匀散布点；
  `pointsNear()` 以半径递减的环形收缩方式，取最靠近指定坐标的点。
- 地图标注换行使用**真实换行符**（`\n`），不可写成字面量 `\\n`，否则标注会直接显示为 `\n`。

### 4.4 交互

| 操作 | 行为 |
| --- | --- |
| 点击地图区域 | 下钻到该行政区 |
| 点击右侧明细表某行 | 下钻到该行对应节点 |
| 面包屑 | 显示当前层级路径，可点击任意层级返回 |
| 「返回」按钮 | 返回上一级 |

ECharts 地图的下钻触发建议用 `inst.trigger('click', { name })`，
直接对 canvas 做坐标点击并不可靠。

## 五、视觉与适配

| 项 | 约定 |
| --- | --- |
| 设计稿 | 1920 × 1080，通过 `fitScreen()` 等比缩放适配实际浏览器窗口 |
| 主色 | 深蓝底（`#04152c` 系）+ 青色主色 `#00d4ff` |
| 语义色 | 告警 `#ff4d4f`、正常 `#7fe3a0` |
| 图表文字 | 页面背景为白色时，图表数值 / 坐标轴 / 图例统一使用**黑色** `#000000` |
| 地图标注 | 折行用真实换行符；标注框宽度足够避免裁剪 |
| 滚动区 | 列表类面板（如「预警未处置 Top5 企业」）需 `overflow-y:auto` **且** 子项 `flex: 0 0 auto`，否则子项会被 flex 压缩而非滚动 |

## 六、数据来源说明

`shared/geo-data.js` 为**江西省行政区划 GeoJSON（公开数据）**，
包含省、市、县三级真实边界，仅用于地图底图渲染，不含任何业务数据。

页面中的业务指标为**演示用数据模型**（由 `ROOT` 总量逐级拆分生成），
接入真实数据时，只需替换 `ROOT` 与 `METRICS` 两个声明，其余渲染与下钻逻辑无需改动。
