YANHUA · PLATFORM

江西省烟花爆竹产业全链条监管服务平台

本工程包含两个可独立运行的数字化系统：全链条监管服务平台（11 个态势页面，覆盖采购、生产、仓储、运输、出口、经营、燃放、打非治违等环节，支持省—市—县—乡镇—企业五级下钻） · 烟花爆竹全链条数字化预警监管平台（风险识别系统，6 个页面，实现库存饱和度、电子围栏与车辆轨迹、异常滞留指数、双风险判定、置信度校验与管控预警）。
全部页面为离线单文件 HTML，双击即可打开，无需联网安装依赖；工程另附模块化算法源码、技术特征对照表与自动化校验脚本。

SYSTEM 01

全链条监管服务平台

省级态势总览与各环节专项态势。基于真实省市县边界的 GeoJSON 地图，支持逐级下钻至企业与点位，实时呈现储量、产能、流向、预警与执法数据。

11 个页面 · 五级下钻 · ECharts 地图进入态势总览
SYSTEM 02

烟花爆竹全链条数字化预警监管平台

面向仓储隐蔽囤货与账面造假的风险智能识别。以实时数据驱动监测时钟，依次完成饱和度计算、围栏轨迹获取、滞留车辆筛选、双风险判定与置信度校验，并输出管控预警。

快速开始
1

打开工程

双击 yanhua-platform.code-workspace，或在 VS Code 中选择「文件 → 打开文件夹」指向本目录。

2

启动预览服务

终端执行 npm run dev；或按 F5 直接调试（会自动拉起服务）。默认地址 127.0.0.1:5180。

3

运行校验

按 ⇧⌘B 运行「全量校验」，或执行 npm run check，检查语法与引用完整性。

4

直接打开也能看

页面均为离线单文件，双击 platform/index.html 或 risk/patent.html 即可，无需任何服务。
